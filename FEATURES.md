# LET v1 Source Feature Matrix

## Implemented in source
- Data models for users, batches, access, content, notifications, chats and tutor page.
- Protected admin password endpoint.
- Google OAuth configuration.
- Profile persistence endpoint.
- Batch CRUD endpoints.
- Access grant/revoke endpoints.
- Content section/item/notification endpoints.
- Cloudinary upload endpoint.
- Conversation/message endpoints.
- Tutor content endpoint.
- WhatsApp buy/enquiry integration.
- Responsive website shell.

## Requires external credentials
- Google login
- Neon database
- Cloudinary uploads

## Requires deployment configuration
- Render environment variables
- Google production redirect URI
